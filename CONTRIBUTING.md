# Contribuindo

Abra uma issue antes de mudanças grandes. Use Python 3.12+, crie testes para regras de escala e rode `pytest`, `ruff check .` e `ruff format --check .`. Nunca inclua dados reais de membros, números de telefone, tokens ou `.env` em issues, testes ou commits. Documente migrações de banco e mudanças de comportamento no pull request.
